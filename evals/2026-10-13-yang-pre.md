## Review

Rerun of `evals/2026-10-12-yang-pre.md` after the full-frame-statistic branch of `leakage-fit-before-split` (a column or frame written back with its own `mean`/`std`/`min`/`max`/`median`/`quantile`/`mode`, or a `groupby(...).transform` with a statistic, before `train_test_split`). Same data, same labels, same script.

Change against 2026-10-12: one more true positive, nb_2760 (z-score written by hand with `desc_mols.mean()` and `.std()` before the split). No new false positive. The five false positives are unchanged: four encoder-fit-before-split cases where Yang labels `N`, and nb_3594 where the `[human errors]` tag suggests the label is wrong.

False negatives (label `Y`, not flagged), read statically:

- nb_1743 — test frame imputed with its own mean via `fillna`; the frame is already a split product, so there is no split call after it.
- nb_3065, nb_678 — Keras `Tokenizer.fit_on_texts` on all rows before the split; Tokenizer is not in the fitted-transformer set.
- nb_195 — file exceeds the 20 MB input cap (exit 3).
- nb_318 — median `fillna` inside a feature function applied to the full data; dataflow does not analyse function bodies.
- nb_296 — hand-written min-max normalisation over the full frame, then `train_test_split`, both inside `def build_decision_tree`; same gap as nb_318.
- nb_89, nb_1633 — refit on test, not fit-before-split.
- nb_2528, nb_1417 — train/test boundary taken by slicing; no split call to anchor on.
- nb_3144 — `LabelEncoder.fit` on train and test concatenated; no split call.

Summary: 2 of 11 misses (nb_318, nb_296) are the full-frame-statistic pattern hidden behind a function boundary; the rest are patterns the detector does not model (Keras Tokenizer, slice splits, refit on test) or the size cap.

## Caveats

Yang labels are the paper authors' manual labels, not re-adjudicated here.
Only `pre` is comparable; Waldean has no class for `overlap` or `multi`.
The 34 notebooks without a `pre` label have Yang's `model` label `N`. None was flagged, so precision and recall are the same with or without them.
